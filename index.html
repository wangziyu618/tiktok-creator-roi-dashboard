干预对照（Before / After）

策略效果追踪 · 累计数据满 2 周后启用
在 data/ 下维护 D_Intervention.csv（干预动作台账：达人 · 干预类型 · 干预周）， 以干预周为分界对比前 2 周 vs 后 2 周的同组达人 GMV / 激活率变化，并保留未干预对照组作基准。 没有对照组，任何"优化有效"都只是自说自话。

建议记录的干预类型：追加 SKU / 提佣 / 催更 / 提供拍摄脚本 / 停止寄样。
MODULE 05

达人明细

全量达人交叉表：点击表头排序、点击层级 chip 筛选、按 handle 搜索、一键导出当前视图。

数据管道：TikTok Shop 后台按周区间导出 → scripts/prepare.py 清洗加列 → 追加至 data/weeks/ → scripts/build_data.py 重打包 → 本页自动包含全部周（纯静态、零依赖）。
校验：node scripts/test_dashboard.js —— 91 项断言覆盖 KPI / 分层 / 漏斗 / 名单 / 渲染，与本页使用同一套计算逻辑。
样品成本口径：$5.0/件（货值 + 头程物流），可在 scripts/prepare.py 中按真实口径调整。设计说明书：Tableau 落地版。
